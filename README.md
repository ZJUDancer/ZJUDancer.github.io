# 项目开发与配置指南

### 1. 核心页面说明
项目当前主要由以下四个核心 HTML 页面构成：
* **Index (首页)**：网站入口及整体展示。
* **Documents (文档)**：技术文档与核心资料展示页。
* **Tutorial (教程)**：分步骤指导与教学内容页面。
* **Team (团队)**：团队成员介绍及组织架构展示。

### 2. 样式与渲染 (CSS)
为了保持界面的整洁与功能分离，样式表分为以下两部分：
* **`main.css`**：**全局样式核心**。存放在此文件中的样式负责支撑整个网页的基础布局与交互视觉。
* **`doc-theme.css`**：**专用于 Markdown 渲染**。该文件主要负责文档内容的美化，确保 Markdown 转换后的文字、代码块等元素具有良好的阅读体验。

### 3. 内容配置与动态渲染 (JS)
文档与教程的内容更新高度自动化，主要依赖以下逻辑：
* **`doc-config.js` (配置文件)**：
    这是内容更新的**唯一入口**。新增文档或教程时，只需在该文件中修改或添加对应的对象即可，关键字段如下：
    * `title`: 页面显示的标题。
    * `file`: 指向对应的 `.md` 文件路径。
    * `docid`: 内部索引 ID（可选）。
* **`markdown-docs.js` (核心逻辑)**：
    负责驱动整个网页的 Markdown 渲染流程，包括自动生成文章侧边栏、处理文件下载功能以及辅助页面的动态交互。

### 4. 资源管理 (Images)
图片资源建议按以下目录结构进行分类存放，以保持项目结构清晰：
* **`images/`**：存放项目通用图片及一级页面素材。
* **`images/media/`**：专门用于存放与 Media 界面相关的多媒体素材。
