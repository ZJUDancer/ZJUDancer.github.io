# 机器人上常用软件安装

## Todesk

在官网下载 arm 架构的 deb 安装包，按照教程操作即可。todesk 连接时需要在机器人的 HDMI 口插入显卡欺骗器（找现场工程师领取，用完插在机器人上一起归还即可）

下载地址：[ToDesk远程桌面软件-免费安全流畅的远程连接电脑手机](https://www.todesk.com)

选择 `Debian/Ubuntu/Mint (arm64)` 版本：

```bash
deb package: https://dl.todesk.com/linux/todesk-v4.8.5.1-arm64.deb
```

安装命令：

```bash
sudo apt-get install ./todesk-vx.x.x-arm64.deb
```

启动命令：

```bash
todesk
```

## Clash Verge

安装包在群里发过：`clash-verge_1.7.3_arm64.deb`

安装命令：

```bash
sudo dpkg -i clash-verge_1.7.3_arm64.deb
```

安装后直接点击应用图标不能正常启动。

第一次启动时需要在终端输入命令：

```bash
WEBKIT_DISABLE_COMPOSITING_MODE=1 clash-verge
```

才能正常启动，启动后导入自己的订阅地址 URL，开启"系统代理"和"开机自启"即可，之后每次开机会自动处于翻墙状态。

## 搜狗拼音输入法

在官网搜索 linux arm64 版本，按照官网教程操作即可。

> ⚠️ 注意：教程里提到的以下两行命令一定要执行：

```bash
sudo apt install libqt5qml5 libqt5quick5 libqt5quickwidgets5 qml-module-qtquick2
sudo apt install libgsettings-qt1
```
