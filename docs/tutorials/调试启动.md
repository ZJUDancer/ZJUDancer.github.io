## 调试启动

在 /core 终端下（可以多开）

1. kill 手柄节点命令：`rosnode kill joy_teleop`

2. 启动机器人命令：`roslaunch dlaunch piplus.launch`
   （停止是 `Ctrl + C`，最好等到机器人停止移动，在转头的时候停止运行）

3. 可以再开一个终端，备好零点复位命令，在机器人原地转头的时候运行，停下机器人：  
   `rostopic pub -r 10 /cmd_vel geometry_msgs/Twist '{linear: {x: 0, y: 0, z: 0}, angular: {x: 0, y: 0, z: 0}}'`

4. 若无法启动机器人可以注意启动五个分启动文件，查看报错信息

5. 启动裁判盒命令：在 `GameController` 路径下，运⾏ `cargo run`
