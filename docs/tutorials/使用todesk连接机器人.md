## 使用 ToDesk 连接机器人

1. 给想连接的机器人插入显卡欺骗器，或者连上显示屏。

2. 在大群里找到最近的一条机器人账号/密码的记录（关键词：`device`），输入账号密码，连接。  
如果没有找到，说明机器人还没有完成初始化配置，可以参考 `新机器人基础配置指南` 里面的 ToDesk 部分。

3. 此时可以操作机器人自身的文件。包括在完成基础配置的时候，可以在下好 ToDesk 之后，在自己的电脑上用 ToDesk 直接连接机器人，在自己的电脑上完成接下来的部分。这样比坐在地上操控鼠标和键盘要方便很多（我是这么想的），虽然可能会比较卡 TOT。

4. 终端运行 `./zed_explorer`（存疑），此时会显示机器人相机画面。

5. 可以抬起机器人转圈，观察画面是否跟着转动。

6. 可以看看画面中的足球是否有被白框标记。

7. 如果都满足，基本可以确认机器人摄像头无问题。
