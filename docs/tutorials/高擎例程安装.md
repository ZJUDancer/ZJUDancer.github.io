# 高擎例程安装

使用 HDMI 线接入机器人背板进入可视化界面，同时插上键盘鼠标直接在机器人小电脑上进行控制，参照下方顺序：

## 步骤一：环境准备

1. 点击右上角进行网络连接
2. 鼠标右键桌面打开终端，输入 `code .` 打开 VSCode
3. 在右下角的终端输入下载代码指令：

```bash
git clone https://github.com/HighTorque-Robotics/RoboCup_Workspace.git
```

1. 在左侧的文件结构找到 `.bashrc` 文件，打开后将下方代码粘贴至 `.bashrc` 文件内容末尾：

```bash
export ZJUDANCER_GPU=1
export LD_LIBRARY_PATH=/usr/lib/aarch64-linux-gnu:/usr/local/cuda-11.4/lib64:$LD_LIBRARY_PATH
export ZJUDANCER_ROBOTID=1
source /home/nvidia/RoboCup_Workspace/core/devel/setup.bash
```

粘贴后保存文件。

---

## 步骤二：编译代码

1. 在现有终端里输入命令：

```bash
source ~/.bashrc
```

再依次进入 `lib` 和 `core` 两个工作空间，编译代码：

```bash
cd lib/
catkin_make
```

等待加载到 100% 后编译完成。

1. 接下来依次输入：

```bash
cd ../core
catkin_make
```

编译成功后，在当前终端再输入一次：

```bash
source ~/.bashrc
```

编译后的代码才能正常执行。

---

## 步骤三：检查相机连接

1. 开机后，需插拔机器人顶部相机线，然后终端输入：

```bash
lsusb
```

会显示找到了 `ZED-M`。

- 如果显示的是 `ZED Hid device`，则相机连接不正常，需要检查接线。

随后有两种显示相机画面的方法（要求通过显示器或 todesk 看到机器人的可视化界面）：

**(1)** 终端输入 `ZED_Explorer`（ZED 官方的测试程序），如果出现正常不闪动的相机画面，则相机功能正常。

**(2)** 终端输入 `roslaunch dvision zed_detect.launch`（视觉识别测试程序），如果出现相机画面，画面中有足球时有方框框起来，则相机功能正常。

如果 `lsusb` 显示了 `ZED-M`，但按照上述两种方法画面都不显示，则相机可能接触不良，可以用：

```bash
watch -n 0.5 lsusb
```

命令每隔 0.5 秒刷新一次 lsusb 状态，如果第一行 ZED-M 显示有闪动，则需要检查相机接线。

如果相机线插拔一次后功能仍不正常，考虑更换相机线。

---

## 步骤四：运行视觉识别

1. 机器人站立解锁，处于可以遥控速度的状态后，关闭手柄控制话题：

```bash
rosnode kill /joy_teleop
```

1. 运行视觉识别程序，终端运行：

```bash
roslaunch dlaunch piplus.launch
```

此时机器人即可自动识别追球。
